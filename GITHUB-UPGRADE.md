# Mise à niveau GitHub

1. Conserver `.github/workflows` dans le dépôt existant.
2. Copier tout le contenu de cette version à la racine du dépôt `algbr`.
3. Remplacer les fichiers portant le même nom.
4. Les anciens fichiers `premium.css`, `styles.css`, `v12.js`, `v13.js` et les anciennes pages peuvent être supprimés après vérification : la V1.4 utilise `style.css`, `app.js` et `project.js`.
5. Commit conseillé : `Rebuild AlGBr website for SEO and conversion`.
6. Attendre le déploiement GitHub Pages vert et recharger avec Ctrl+Shift+R.
