FAQ

Les questions avant de commencer.

Puis-je commencer avec un petit budget ?

Oui. Nous pouvons isoler le besoin prioritaire, lancer une première version utile puis ajouter les fonctions lorsque le projet le justifie.

Qui héberge le site ?

Le site peut être publié sur GitHub Pages, Firebase Hosting ou un hébergeur adapté à vos besoins. Le choix dépend des fonctions, du trafic et des données utilisées.

Puis-je modifier les contenus moi-même ?

Oui. Selon le projet, nous fournissons un fichier de configuration simple, une interface d’administration ou une formation rapide.

Le support continue-t-il après la livraison ?

Oui. Vous pouvez choisir une intervention ponctuelle ou un forfait de suivi avec mises à jour, corrections et conseils.
