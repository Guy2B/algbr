# Validation — Al.G.B.r. Studio V1.3

## Contrôles réussis

- syntaxe JavaScript : `app.js`, `project.js`, `v13.js` ;
- analyse HTML des pages principales ;
- absence d’identifiants HTML dupliqués ;
- présence des ressources locales référencées ;
- logo officiel Lune Beauty utilisé depuis `assets/` ;
- visuel officiel Lune Beauty utilisé depuis `assets/` ;
- liens configurés vers Lune Beauty et Σ Life OS ;
- styles responsive pour ordinateur, tablette et téléphone ;
- prise en charge de `prefers-reduced-motion` ;
- aucun secret ou fichier `.env` inclus ;
- intégrité des archives ZIP et empreintes SHA-256.

## Limite de l’environnement de construction

Le navigateur Chromium de l’environnement bloque l’ouverture des pages locales et du serveur local avec `ERR_BLOCKED_BY_ADMINISTRATOR`. La recette visuelle finale doit donc être réalisée sur GitHub Pages après déploiement.

## Recette recommandée

1. ouvrir la page d’accueil sur ordinateur ;
2. vérifier le logo Al.G.B.r. dans l’en-tête ;
3. vérifier le visuel et le logo officiel Lune Beauty ;
4. tester les liens Lune Beauty et Σ ;
5. ouvrir l’Architecte de projet ;
6. activer le preset Lune Beauty ;
7. tester FR, DE et EN ;
8. vérifier l’affichage sur téléphone ;
9. tester le mode mouvement réduit ;
10. contrôler les pages légales et de confidentialité.
